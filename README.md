# SenseAgent-LoRA-Dataset

**异构感知资源编排微调数据集** — 面向智能体驱动的无线感知系统。

## 概述

本仓库包含一个 Alpaca 格式的 LoRA 微调数据集，用于训练智能体驱动的无线感知异构资源编排大脑。数据集由 24 条高质量指令样本组成，覆盖三大主流无线感知技术路线：

- **WiFi CSI 感知**：人体活动识别、人群计数、穿墙检测、呼吸监测、室内定位、通感一体化
- **毫米波雷达感知**：生命体征监测、手势识别、跌倒检测、4D 点云追踪、隔墙声音恢复
- **超宽带（UWB）雷达感知**：穿墙人体检测、高精度室内定位、应急搜救

## 数据来源

每条样本的推理逻辑均基于近十年（2016-2026）发表于 IEEE Xplore 和 arXiv 的学术文献，包括但不限于：

- CSI-Bench (NeurIPS 2025) — 大规模多任务 WiFi 感知基准
- EfficientFi — WiFi CSI 压缩传输框架
- SPARCS — 60GHz 通感一体化人体感知
- mmFall — 4D 毫米波雷达跌倒检测
- FEEL — UWB/IMU 融合定位
- 以及 IR-UWB 穿墙雷达等相关工作

## 数据格式

严格遵循 Alpaca JSON 格式，每个样本包含三个字段：

| 字段 | 说明 |
|------|------|
| `instruction` | 固定指令：智能体驱动的异构感知资源编排任务 |
| `input` | 任务意图与环境状态描述 |
| `output` | 设备选型决策及物理层推理依据 |

## 用途

此数据集可用于对开源大语言模型（如 Llama、Qwen、DeepSeek 等）进行 LoRA 微调，使其具备以下能力：
- 根据任务需求和环境约束自动选择最优感知设备
- 理解不同无线信号（WiFi、毫米波、UWB）的物理特性与适用场景
- 生成可解释的传感器融合与参数配置方案
